VISUAL FRAMEWORK — MACHINE LEARNING ALGORITHMS

The Algorithm Dispatch Board

Ten algorithms, routed onto two lines by how they learn. Each station shows what the algorithm is built for, how it works, and where it earns its keep — from tabular forecasting to generative AI.

Supervised — learns from labeled examples Unsupervised — finds structure without labels

Supervised Line

05 STATIONS
TABULAR

XGBoost

Builds decision trees one after another, where each new tree is trained to correct the errors left by the ones before it, then blends all their votes.

Use case: Freight rate prediction, credit scoring, fraud flagging on transaction tables.

NLPSEQUENCE

Hidden Markov Model

Treats a system as moving through a chain of hidden states over time, and works backward from what was observed to the most likely sequence of states.

Use case: Speech recognition, and inferring equipment failure stages from a string of sensor readings.

COMPUTER VISION

Convolutional Neural Network

Slides small learned filters across an image to pick up edges and textures, then stacks layers so simple patterns combine into recognition of full objects.

Use case: Automated container or freight damage inspection, manufacturing defect detection.

NLPGENERATIVE AI

Transformer (Self-Attention)

Weighs how relevant every word in a passage is to every other word at once, so it captures context and long-range meaning without reading strictly left to right.

Use case: Machine translation, customer-service chatbots, document summarization.

TABULARNETWORK DATA

Graph Neural Network

Passes information along the connections between related records, so each node's prediction reflects both its own data and its neighbors' data.

Use case: Supply-chain risk propagation, fraud-ring detection, logistics network optimization.

Unsupervised Line

05 STATIONS
TABULAR

Isolation Forest

Randomly splits the data over and over; genuine outliers get separated from the rest in far fewer splits than typical points, which is how it flags anomalies.

Use case: Predictive maintenance — catching abnormal sensor readings before equipment fails, transaction fraud screening.

TABULARGEOSPATIAL

DBSCAN

Groups points that are packed closely together into clusters and labels sparse, isolated points as noise, with no need to pre-set how many clusters exist.

Use case: Grouping delivery stops into route clusters, segmenting customers by behavior without a fixed number of tiers.

GENERATIVE AI

Generative Adversarial Network

Pits two networks against each other — one generating fake samples, one trying to catch the fakes — and the competition pushes the generator toward realism.

Use case: Synthetic training data generation, product catalog image generation.

COMPUTER VISIONTABULAR

Autoencoder

Compresses input down to a small representation and then tries to rebuild the original from it; inputs that reconstruct poorly stand out as unusual.

Use case: Network intrusion detection, image denoising and compression.

NLP

Word2Vec (Skip-gram)

Trains a shallow network to predict the words around a given word; the byproduct is a set of vectors where words used in similar contexts end up near each other.

Use case: Powering search and recommendation relevance, grouping support tickets by topic.
